windows powershell 常用命令集合

# 上下分屏

- 组合键：Alt + Shift + - (减号)

# 左右分屏

- 组合键：Alt + Shift + + (减号)

# 调整大小
- 组合键: Alt + shift + 方向键

# 关闭分屏幕
- 组合键：Ctrl + Shift + W 或直接输入 exit + 回车

# 切换焦点
- 组合键： Alt + 方向键，可以在左右不同的窗格间移动

# 命令模糊匹配
- F8 输入你的命令然后按F8可以更具当前命令快速匹配历史命令
